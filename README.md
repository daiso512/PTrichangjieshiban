🏭 CAR2 PT 组日常通知看板 (V2.0) 使用说明本看板旨在为 PT 团队提供一个高效、直观的信息共享平台，支持移动端和 PC 端访问，具备通知发布、历史查询、图片附件及中日双语切换功能。
🛠️ 核心功能模块1. 公告看板 (View Mode)跑马灯实时通知：自动筛选并循环播放当日发布的“紧急”或“普通”通知，确保关键信息第一时间触达。卡片式布局：采用 Expander 折叠卡片，标题包含日期、优先级图标、责任人和内容摘要，点击即可展开查看详情。多媒体支持：每条通知可附加多张图片，支持点击放大查看。全局搜索：支持按关键词或责任人实时过滤历史记录。报表导出：提供一键导出 CSV 功能（已处理 UTF-8 编号以兼容 Excel），方便存档和离线分析。2. 管理后台 (Admin Mode)身份验证：侧边栏集成管理员登录功能（默认密码：123456）。登录后方可操作增删改。发布通知 (Create)：支持选择日期、分类（日常、品质、注意等）和优先级。支持批量上传图片附件。编辑记录 (Update)：通过 ID 索引快速读取现有数据进行修改。删除记录 (Delete)：支持物理删除失效或错误的记录，同时自动清理关联的图片数据。🏗️ 技术架构技术栈前端框架: Streamlit (Python-based)数据库: SQLite3 (本地轻量级关系数据库)数据处理: Pandas (用于搜索过滤与报表导出)样式定制: HTML/CSS 注入（隐藏 Streamlit 默认页眉/页脚，优化 UI 视觉感）数据库结构系统自动创建并维护 notifications_v2.db 文件，包含两个关联表：notifications: 存储通知文字信息（ID, 日期, 内容, 级别, 分类, 责任人）。images: 以 BLOB 格式存储图片二进制流，支持一对多关联（一条通知多张图）。🌍 多语言支持系统内置中日双语词典，用户可在侧边栏随时切换。功能项中文 (CN)日本語 (JP)标题日常通知看板掲示板级别示例普通 / 紧急 / 重要普通 / 緊急 / 重要分类示例品质管理 / 注意事项品質管理 / 注意事項🚀 部署与运行环境准备：确保安装了 Python 3.8+ 及其依赖库：Bashpip install streamlit pandas
